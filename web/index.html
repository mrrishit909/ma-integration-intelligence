M&A Integration Intelligence

An invented acquisition: a data room read by rules for change-of-control clauses and cyber findings, two customer masters matched into one entity graph, synergies as distributions from a model fitted to a database of past deals, overlapping applications, fast against staged ERP integration, a decision with four eyes, and the first year of synergy reports, every number set against the simulation truth. …
The companies, customers, contracts, cyber findings, applications, the deal database and the true process behind it are generated by a simulator in this repository; nothing is a real company, deal or vulnerability. The truth is shown only to judge the models, which never see it. The parsers are hand-written rules and the executive summary is filled-in templates: no language model or outside service is called.
